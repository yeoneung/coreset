# Covariance-aware diffusion warm starts

Code for conditional diffusion with mean-only, diagonal, low-rank, and full
Gaussian sources. This repository provides experiment scripts, cached results,
and the data and fitted models needed for the covariance-source ablation.

## Contents

- `code/nab/`: environments, models, training, evaluation, control, and plotting.
- `code/experiments/`: source ablations, anchor training, calibration, and rank studies.
- `code/plots/`, `code/replot.py`: plotting from cached outputs.
- `code/tests/`: covariance, score-evaluation-count, and result-schema checks.
- `artifacts/`: source-ablation data, reference costs, and fitted checkpoints.
- `results/`: JSON summaries and saved generated-image tensors.
- `figures/`, `tables/`: rendered computational outputs.

See `code/README.md` and `artifacts/README.md` for details.

## Quick start

Run from the repository root:

```powershell
python -m pip install -r requirements.txt
python code/tests/test_covariance.py
python code/tests/test_reporting.py
python code/tests/test_result_schema.py
python code/replot.py
```

These checks and cached plots require no training or reverse sampling.
The analytic and schematic plots have separate entry points:

```powershell
python code/theory_bounds.py
python code/plots/anchor_overview.py
```

## Experiments

Use the included score model and conditional diagonal-anchor checkpoint:

```powershell
python code/experiments/covariance_anchor.py --seeds 3
python code/experiments/covariance_anchor.py --nfe 8 --t-starts 123 --seeds 3 --output results/covariance_nfe8.json
python code/plots/covariance_anchor.py
```

Optional anchor retraining and other focused experiments:

```powershell
python code/experiments/train_wsd_anchor.py --epochs 600
python code/experiments/calibration.py --seeds 3
python code/experiments/rank_mi.py
```

`run_covariance_experiment.ps1` retrains the anchor and runs both source
ablations. `run_extra_experiments.ps1` runs calibration and rank studies.
`reproduce.ps1` regenerates the analytic and schematic plots. These wrappers
do not require LaTeX. Experiment commands overwrite their cached outputs;
use a separate clone to preserve this version. A CUDA device is recommended
for learned-model experiments.

## Evaluation conventions and scope

`n_steps`, `--nfe`, and JSON `nfe` fields count interpolation intervals.
Actual score calls include the final clean reconstruction and equal
`min(n_steps + 1, t_start + 1)`: interval settings 4 and 8 use 5 and 9
calls in the ablation, and the 128-interval full run uses 129.
Source prediction, guidance, and polishing are outside this score-call count.

Plots use shared readable labels and below-panel legends. The dotted anchor
curve is scaled residual RMS per trajectory point, not conditional mean
error. The pendulum guidance sweep contains weights `0, 0.1, 0.25, 0.5, 1,
2, 4`; its displayed panel includes the five weights up to 1.

The full-budget/few-step study uses `artifacts/data/test_ref_known.pt`
(mean reference cost 2.15012); the covariance study uses
`artifacts/data/test_ref.pt` (11.00393). Cost-gap magnitudes are not directly
comparable between these studies.

The source ablation uses 6,804 training trajectories and 488 held-out
conditions. The WSD-style predictor changes only the source for a frozen
VP generator; it is not a full WSD generator comparison. This pooled ablation
does not validate the finite-sample rank/entry confidence rule.

Larger datasets and checkpoints for the other benchmarks are not included.
Generation and training entry points are in `code/nab/`; cached summaries
and rendered results are provided. `value.pdf` and `frontier.pdf` are
additional guidance diagnostics generated by the plotting code.
